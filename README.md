# 📝 WordAutoWriter-WAW-V1

**```WordAutoWriter-WAW-V1```** is a Python desktop application that automates Microsoft Word document creation. It allows users to enter a title and text, select a writing speed, and automatically type the content into Word. It also supports pause, resume, stop, and saving documents in **```.docx```** format.

## ✨ Features :

- Add a document title and text
- Automatic character-by-character writing
- Adjustable writing speed
- Pause and resume writing
- Stop the writing process
- Clear the text area
- Automatically insert the current date
- Save documents in Word **```.docx```** format
- Automatic Microsoft Word control

## 🚀 How It Works

- **The user** enters a title and text into the application interface and selects a writing speed. 
- **The application** opens Microsoft Word, creates a new document, adds the title, current date, and automatically types the provided text.
- **The final document** can then be saved in **```.docx```** format.

## 🎮 Controls

- **Commencer:** Starts the automatic writing process.
- **Pause:** Temporarily pauses the writing.
- **Arrêter:** Stops the automatic writing.
- **Effacer:** Clears the text area.

## 📋 Requirements :

Before running **```WordAutoWriter-WAW-V1```**, make sure you have:

- Windows operating system
- Python 3.x
- Microsoft Word installed
- PyWin32 library

## 📦 Installation :

- Install the required Python package: `pip install pywin32`
- You can also install it using: `python -m pip install pywin32`

## ▶️ Run the Application :

- Navigate to the project folder: `cd WordAutoWriter-WAW-V11`
- Then run: `python WordAutoWriter-WAW-V1.py`
